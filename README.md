Une application Django pour gérer les employés, leurs salaires, et les importer/exporter via fichiers Excel. Interface moderne 

---

## 🚀 Fonctionnalités

-  CRUD Employés
-  Import/Export Excel
-  Pagination 
-  Interface  avec tableau de bord
-  Déploiement sur Render

---


### 1. Cloner le projet

git https://github.com/Isaac2910/ExcelDataManager.git


## Installer les dépendances

pip install -r requirements.txt


## Appliquer les migrations

python manage.py migrate

### Lancer le serveur de dev
python manage.py runserver
